# TaskFlow - Product Requirements

## Problem

People need a simple way to create and track tasks on their phone, and to load many tasks at once from a CSV file. It must work without internet.

## Users

Individuals managing their personal or work tasks.

## In scope

- Six screens: Dashboard, Task List, Add / Edit Task, Task Details, Bulk Upload, Settings
- Tasks saved on the phone (offline)
- CSV import with validation
- CSV export
- Light and dark theme

## Out of scope

- Backend server
- Login / accounts
- Sync between devices
- Notifications

## Success

- All six screens work
- CSV import checks every row and reports the bad ones
- The app installs on an Android phone from an APK
